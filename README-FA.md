# اجرای دوک روی Render برای تست

این بسته مخصوص سرویس Node در Render است و شامل خروجی آماده، تصاویر، کد منبع، ورود مستقل مدیریت و هشدار ذخیره کد پیگیری است. به ChatGPT یا حساب Cloudflare وابسته نیست. پرداخت فقط دمو است.

## راه‌اندازی
۱. ZIP را استخراج کنید. محتوای پوشه DOOK-Render را داخل یک مخزن GitHub قرار دهید؛ package.json و render.yaml باید در ریشه مخزن باشند. خود فایل ZIP را آپلود نکنید. Render برای این روش مخزن کد را دریافت می‌کند.
۲. در Render گزینه New → Web Service را بزنید و مخزن را متصل کنید.
۳. تنظیمات:
- Language: Node
- Instance Type: Free
- Build Command: npm ci --omit=dev --no-audit --no-fund
- Start Command: node launcher.mjs --no-open
- Health Check Path: /healthz
۴. در Environment متغیر ADMIN_PASSWORD را با رمز دلخواه ۶ تا ۲۵۶ کاراکتری تعیین کنید. رمز را در فایل کد یا GitHub ننویسید. متغیر NODE_VERSION را 22.16.0 و HOST را 0.0.0.0 قرار دهید.
۵. Create Web Service را بزنید و تا پایان Deploy منتظر بمانید. Render یک آدرس onrender.com می‌دهد. برنامه آدرس و پورت Render را خودکار دریافت می‌کند.
۶. مدیریت در /admin است. با همان ADMIN_PASSWORD وارد شوید. برای تغییر رمز، مقدار متغیر را در Render تغییر دهید و سرویس را دوباره راه‌اندازی کنید.

روش جایگزین: New → Blueprint و انتخاب همین مخزن؛ render.yaml تنظیمات بالا را آماده کرده و فقط رمز را از شما می‌خواهد.

## محدودیت مهم پلن رایگان
اطلاعات این نسخه روی دیسک محلی ذخیره می‌شود. در Render رایگان پس از خواب سرویس، restart یا deploy، سفارش‌ها، موجودی و تصاویر آپلودشده ممکن است پاک شوند و محصولات اولیه دوباره ساخته شوند. رمز از متغیر محیطی دوباره خوانده می‌شود. این نسخه برای آزمایش و نمونه‌کار است، نه سفارش واقعی.
سرویس رایگان پس از ۱۵ دقیقه بی‌فعالیتی می‌خوابد و بازشدن بعدی ممکن است حدود یک دقیقه طول بکشد.
برای اطلاعات ماندگار باید دیتابیس/فضای ذخیره‌سازی خارجی یا پلن دارای دیسک پایدار تنظیم شود. در حالت دیسک پایدار، DATA_DIR را برابر مسیر mount قرار دهید. این فایل هیچ سرویس پولی خودکار ایجاد نمی‌کند.

## خطایابی
- خطای ADMIN_PASSWORD: متغیر را در Environment تنظیم کنید.
- No open ports: Start Command و HOST را مطابق بالا وارد کنید.
- Invalid host: برای دامنه سفارشی PUBLIC_ORIGIN را برابر آدرس کامل HTTPS همان دامنه تنظیم کنید. برای onrender.com نیازی نیست.
- عکس یا سفارش آزمایشی ناپدید شد: محدودیت دیسک موقت پلن رایگان را بررسی کنید.
- کمبود حافظه یا خطای workerd: لاگ Deploy را بررسی کنید؛ اجرای واقعی روی حساب Render هنوز آزموده نشده است.

این بسته موتور Worker را با Miniflare در Node اجرا می‌کند؛ مناسب تست است. لینک‌های canonical و sitemap در خروجی اصلی هنوز به آدرس Sites اشاره دارند؛ برای ارائه نهایی روی دامنه جدید باید از منبع دوباره ساخته شوند.
